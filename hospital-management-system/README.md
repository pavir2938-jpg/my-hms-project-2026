# CarePlus Hospital Management System

A responsive front-end demo inspired by the Hospital Management System reference image.

## Run in Visual Studio Code
1. Extract `hospital-management-system.zip`.
2. Open the `hospital-management-system` folder in VS Code.
3. Open `index.html` in your browser, or install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

## Included screens
- Login
- Admin dashboard and appointment overview
- Patient registration
- Appointment booking
- Doctor management
- Patient records
- Billing
- Pharmacy inventory
- Laboratory reports
- Admissions and discharge
- Staff management
- Reports and analytics

## Notes
This is a front-end demonstration. Form submissions update the page in browser memory only. A real hospital deployment needs a secure backend, database, authentication, access controls, audit logs, backups, and privacy/security review. Do not enter real patient information into this demo.
